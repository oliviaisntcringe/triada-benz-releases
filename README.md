# triada.benz releases

Public downloads for the Windows x64 launcher, Release/Debug DLLs, loader and navcache. The source project remains private. Model packs are not included.

Download **triada.launcher.exe** from [the latest release](https://github.com/oliviaisntcringe/triada-benz-releases/releases/latest). Run it, select your CS2 `game` folder in Settings and use Launch. The launcher downloads the selected DLL and loader from this repository and verifies SHA256. No GitHub login or token is required. .NET Framework 4.8 is required on Windows.

The Nav tab installs the navigation cache. Existing local Workshop model libraries remain available; remote model downloads are currently paused.

Command-line package checks remain available: `triada.launcher.exe check`. Checksums for every downloadable build are included in `SHA256SUMS.txt`.
